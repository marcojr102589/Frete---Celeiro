# Cotador de Frete - Celeiro Sementes

Este é um aplicativo web em Streamlit para calcular o custo de frete por km e tonelada, com distâncias obtidas do Google Maps.

## Como usar

1. Digite origem e destino (ex: Luziânia, GO para Rio Verde, GO)
2. Informe o peso transportado (em toneladas)
3. O sistema mostrará os custos por transportadora
